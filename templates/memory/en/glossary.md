## Approved terms (dictionary)

Dictionary of authority for rule 5 of `memory/writing-rules.md`: one concept carries one name.
Uniqueness holds inside a context: the `Context` column names the bounded context of the term.
An agent that meets a concept without an approved name adds a row here. It never invents a synonym. The code of a context reuses its approved
terms: classes, methods, use cases, value objects.
